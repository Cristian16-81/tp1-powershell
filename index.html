TP1 - PowerShell

Alumno: CristianMiranda

Materia: Programación para Seguridad Informática

Sistema: Linux Mint

Descripción

Script en PowerShell Core que obtiene información del sistema:

  • Versión de PowerShell
  • Política de ejecución (permisos)
  • Información del sistema operativo
  • Información completa de la PC (comando bash)

Ejecución

pwsh -File ./script.ps1
Nota: Este TP fue adaptado de Windows a Linux Mint usando PowerShell Core multiplataforma.
